# DevloperAkademi – Eğitim Platformu Web Sitesi

## 📌 Proje Hakkında

DevloperAkademi, yazılım eğitimlerini ve eğitim ekibini tanıtmak amacıyla geliştirilmiş bir web sitesi projesidir.

Bu proje, üniversite dönem projesi kapsamında hazırlanmıştır. Kullanıcıların platform hakkında bilgi edinebileceği, sunulan eğitimleri inceleyebileceği ve ekip üyelerini tanıyabileceği bir web arayüzü sunar.

## 🚀 Özellikler

- Ana sayfa ve platform tanıtımı
- Hakkımızda bölümü
- Misyon ve vizyon alanları
- Eğitim kategorilerinin listelenmesi
- Eğitim kartları ve tanıtım alanları
- Ekip üyelerini tanıtan bölüm
- İletişim sayfası ve form arayüzü
- Sayfa içi gezinme menüsü
- Ayrı panel giriş ve yönetim paneli arayüzleri
- İkon ve özel yazı tipi desteği

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome
- Google Fonts

## 💻 Kurulum ve Çalıştırma

Projeyi bilgisayarınızda çalıştırmak için:

1. GitHub üzerinden projeyi klonlayın:

```bash
git clone https://github.com/mirac-kala-dev/devloper.git
```

2. Proje klasörüne girin:

```bash
cd devloper
```

3. `index.html` dosyasını tarayıcıda açın.

Visual Studio Code kullanıyorsanız Live Server eklentisiyle de çalıştırabilirsiniz.

## 📝 Geliştirme Notları

- Proje, eğitim platformu konseptinde hazırlanmış bir web arayüzüdür.
- Eğitim ve ekip alanlarında örnek içerikler bulunmaktadır.
- İletişim formu arayüzü hazırlanmıştır; çalışan bir backend veya veritabanı entegrasyonu bulunmamaktadır.
- Panel sayfaları arayüz niteliğindedir; aktif kullanıcı doğrulama sistemi içermez.
